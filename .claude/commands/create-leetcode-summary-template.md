# LeetCode 题解模版生成器

你将为 LeetCode 题目创建一个标准化的题解模版文件。

## 使用方式
`/create-leetcode-summary-template 189"`

## 参数说明
- `$1` - LeetCode 题号（必需）

## 任务流程

1. **参数校验**
   - 验证题号是否为数字
   - 验证分类目录是否有效

2. **生成模版**
   - 根据提供的参数生成标准化模版文件
   - 文件路径：`src/{分类目录}/{题号}-{题目名称}.md`
     - {分类目录}你根据src下每个目录的readme去决定放到哪个目录下.
   - 命名规范：参考项目现有文件格式

## 生成的模版示例

根据项目现有的题解格式（如 189-.md、169-MajorityElement.md），创建包含以下内容的文件：

```markdown
# [题号] [题目名称]

## 第一次提交

\`\`\`ts
「占位」
\`\`\`

问题:
- [ ] 待补充

分析:
- [ ] 待补充

时间复杂度: O(?)
空间复杂度: O(?)
```

## 执行步骤

1. 验证输入参数的有效性
2. 构建完整的文件路径
3. 检查文件是否已存在（如存在则提示）
4. 生成标准化模版内容
5. 创建文件并确认成功

最终生成的文件应该在 `src/{分类目录}/` 下。
