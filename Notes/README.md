## 思维模式训练:

哈希表(Set, Map):
- 重复需要“找”的操作
- 空间换时间

双指针:
- 特征:有序、原地、O(1)、不重复
- 慢指针: 指向要改的; 快指针: 指向遍历的.
- 有限考虑,先动快指针,慢指针不动的场景

贪心算法:
- 股票I 时非常好用,也就是有条件的区间计算

动态规划三步走: (参考 leetcode 70)
1. 状态定义: dp[i] = 答案
2. 转移方程: 思考前一步, 互斥且完备的方式
3. 确定边界条件. dp[1] = ?; dp[2] = ?;

## 时间复杂度:
### 常见TC
   - `JSON.stringify(nums)` 需要遍历整个数组并序列化为字符串，时间复杂度 O(n)
   - `JSON.parse()` 需要解析字符串并重建数组，时间复杂度 O(n)
   - `Array.prototype.sort()` 的平均和最坏情况时间复杂度通常是 O(n log n)
   - nums.sort((a, b) => (b - a)) 传回调降序, 不要默认,默认是字符串比较
   - 深拷贝: O(n)
### 其他技巧:
- 善用注释,比如双指针 空格字符串+短横线
- `[...map]` 可以展开成`[[k1,v1],[k2,v2]...]`
- ide补全要检查
- 数组越界喜欢坑人
- 对比并赋值,使用Math.min/max
- 自习检查边界条件,至少要脑子过题意两边.

### leetcode规则
   - LeetCode 通常限制时间在 1-2 秒内
   - 对于 O(n²) 算法，当 n > 10^4 时容易超时
   - 对于 O(n³) 算法，当 n > 500 时容易超时
